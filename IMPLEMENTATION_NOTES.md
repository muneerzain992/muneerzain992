## Important

The correct project name is **MerApp CRM** everywhere. The CRM is labelled PRIVATE and has no link to a private repository. No social media or email links have been included.

## Publish manually

1. Open `https://github.com/muneerzain992/muneerzain992`.
2. Choose **Add file → Upload files**.
3. Upload the extracted `README.md` and `assets/` files, preserving the folder paths (do not upload the ZIP itself).
4. Commit changes to the `main` branch, replacing the existing README.
5. Visit `https://github.com/muneerzain992` and verify the rendered visual sections and the two public project links.

Existing `ezgif-5eb4a6208e623883.webp` is not deleted by these instructions; it simply will no longer be referenced.

## Why PNG instead of animated SVG

GitHub does not reliably animate SVG files embedded in a README. The five PNG panels render consistently across desktop and mobile GitHub. The included visual illustrations are static and contain no scripts or external dependencies.
